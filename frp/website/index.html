FAQ

Veelgestelde vragen.

Kan ik mijn key met een vriend delen?

Nee. Een key wordt bij de eerste activatie aan jouw apparaat gekoppeld. Nieuwe pc? Vraag een reset aan.

De balk wordt niet herkend.

Zet Future in venstermodus zonder rand. Gebruik daarna “Test detectie” en verschuif het zoekgebied tot het oplicht.

Hoe werkt de afstandsbediening?

Zet hem aan in de app, open de remote-pagina op je telefoon en vul de code in. Staat hij uit, dan kan niemand meekijken. Alleen jij ziet de code op je eigen pc.

Windows of mijn antivirus waarschuwt me.

Macro’s die toetsen simuleren worden vaak gemarkeerd omdat de app niet digitaal is ondertekend. Kies “Toch uitvoeren” of voeg een uitzondering toe.
